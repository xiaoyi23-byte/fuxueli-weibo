# 小梨微博模拟器 · Public Edition（不含《破晓》）

独立的 Streamlit 公开体验版，基于原版 v6 制作。**本版本没有《破晓》内容包，也不会连接、读取或修改私人的 Neon 数据库。**

## 部署

1. 将压缩包内的文件上传到 GitHub 仓库；不要上传 `secrets.toml` 或任何数据库密码。
2. 在 Streamlit Community Cloud 选择仓库和 `main` 分支，主入口为 `app.py`。
3. 本版不需要 Neon 数据库，也不需要配置 Secrets；如果复制了旧应用配置，请清空数据库相关 Secrets。
4. 发布前确认仓库不存在 `po_xiao_preset.py` 和 `pages/03_破晓内容包.py`。

## 访客数据规则

- 每个浏览器会话有独立人物资料，首次打开使用演示人物。
- 人物编辑、头像上传及 JSON 备份导入只影响当前会话，不会写入共享数据库或云端文件。
- 「常用人物 → 人物库备份与迁移」可下载 JSON；下次访问时自行导入。
- 微博、评论和配图也只在当前会话内编辑，可导出 PNG 或 ZIP。
- 刷新页面、断线或关闭会话可能清除未导出的编辑。

原版 v6 保留在你本地，继续用于《破晓》内容和原有数据。公开版不提供跨设备同步或永久云端保存。
